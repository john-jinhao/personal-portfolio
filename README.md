# John Oh — Facilities Management Portfolio

A static React + TypeScript portfolio site for John Oh, Senior Facilities Executive in Singapore.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL reported by Vite. Create an optimised production build with:

```bash
npm run build
npm run preview
```

## Deployment

The site is a static Vite app. Deploy the contents of `dist/` after `npm run build` to Netlify, Vercel, GitHub Pages (with an appropriate Vite `base` setting) or any static hosting provider.

## Editing content

- Update project scopes and capability cards in `src/data/portfolio.ts`.
- Update layout and presentation in `src/App.tsx` and `src/styles.css`.
- Supplied images are served from `resources/` by Vite.
